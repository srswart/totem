Anthropic cloud sessions" — phrasing that implies live interactive
attachment testing against each real application. A headless cloud sandbox
running this investigation cannot do that literally: there is no Cursor
instance, no Claude Desktop instance, and no separate harness to attach
*from* here. This was corrected plainly in the advance's Outcome section,
per harness:

- Claude Code (desktop + web sessions) and the Claude API MCP connector:
  backed by primary-source documentation fetched live from
  `code.claude.com` and `platform.claude.com`, plus — for Claude Code web
  sessions specifically — direct self-observation, since the session
  running this investigation *is* one, with live MCP connections at the
  time of writing.
- Cursor (local + background agents): genuinely **not verified**.
  `docs.cursor.com` returned `CONNECT tunnel failed, response 403` via both
  `curl` and the `WebFetch` tool. What's recorded instead is sourced from
  `WebSearch` summaries of third-party 2026 setup guides, explicitly
  labeled in the findings doc as unverified secondary sources — not
  confirmed against Cursor's own documentation or a live session.

This gap is carried forward into `ADV-GATEWAY-003`'s risk section rather
than resolved by softer language.

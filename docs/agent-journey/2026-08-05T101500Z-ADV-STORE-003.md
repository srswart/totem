## What was implemented

**ADV-STORE-003 — Investigation: embedding provider + placement spike —
complete.**

Investigation mode, empty `work_products`, no production code — the
deliverable is a recorded recommendation plus disposable spike code, per
`arrive/agent-rules/advance-profiles.md`. No `tdd:red-green` or `tidy_first`
claimed; both recorded `not_applicable` in frontmatter with rationale.

Built `crates/totem-embedding-spike` (new workspace member, no dependents):
a 10-text memory-shaped corpus, five hand-labeled queries (four sharing
vocabulary with their target, one deliberately paraphrased away from it),
an `EmbeddingProvider` trait, and one real candidate — `HashingEmbedder`, a
character-trigram hashing trick with cosine similarity. Three tests
(`cargo test -p totem-embedding-spike`) assert it wins on lexical-overlap
queries and loses on the paraphrase (a negative control proving the finding
isn't cherry-picked), plus a unit-length sanity check. All pass, offline,
deterministic.

The other two candidates in scope — an API-based provider and a local
pretrained model (`fastembed`) — could not be executed. A real HTTPS probe
(`examples/probe_api_reachability.rs`, honoring `HTTPS_PROXY`) against four
embedding-API hosts plus a known-good control host (`index.crates.io`)
found the control succeeds and every embedding-API host fails identically
with `Proxy failed to connect` — the same class of egress block
ADV-STORE-004 hit for `download.surrealdb.com`. `fastembed` downloads its
model weights on first use, so it's blocked the same way; that claim is
sourced from a web search of the crate's own docs, not independently run.

Findings, verdict, and recommendation are recorded in
`docs/tech-direction/embeddings.md` (EMB-001–EMB-003): recommend a local
pretrained model, embedded synchronously at gateway-write time, API-based
embedding as an explicit non-default opt-in, and curator-owned
re-embedding triggered by model-version changes. The recommendation is
stated plainly as **partially** evidence-backed — one measured local
baseline plus unverified secondary-source specs for the other two
candidates, not a head-to-head measurement — and that gap is carried
forward as residual risk to ADV-STORE-002.

During development, the first version of the package-manager query failed
its own test for real (top-1 came back wrong, rank 9 of 10) because it
didn't actually share enough trigram substrings with its target text.
Reworded and re-verified before committing; documented honestly in the
advance's Changes Made rather than folded away silently.

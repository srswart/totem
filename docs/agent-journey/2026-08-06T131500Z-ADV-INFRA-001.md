## Findings

- **Async engine close.** Dropping the last store handle releases the RocksDB
  lock a moment later (the SDK's router task runs `kvs.shutdown()` on channel
  close). Real restarts are process exits and never see it; same-process
  reopens need a bounded retry. Recorded in the advance's Risk section and
  the durability test's docs.
- **Authored scope met reality.** The CLI "islands" the advance was written
  to fix belong to the losing CLI-001 collision implementation; the merged
  CLI was already a pure gateway client. Scope corrected in the advance, not
  silently narrowed.
- **Notes don't gate; dependencies do.** GATEWAY-003's "after INFRA-001"
  ordering existed only as prose until this session wired it as a plan
  dependency — before the claim was pushed, an Opus firing could legitimately
  have started auth work on the demo topology. Shawn's question surfaced it.

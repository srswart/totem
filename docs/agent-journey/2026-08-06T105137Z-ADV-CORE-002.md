`docs/tech-direction/value-attribution.md` (ADV-CORE-004's investigation,
merged into this same phase branch) gave a concrete v1 signal set to
implement rather than a blank objective: lead with citation
(`provenance.derived_from`), do not weight raw retrieval into `value_score`
directly, defer explicit feedback (zero data points, the tool doesn't exist
yet).

Read `crates/totem-core/src/{record,category,provenance}.rs` and
`crates/totem-store/src/{memory,row,schema}.rs` before writing anything.
One finding from that reading changed the design: `schema.rs`'s own doc
comment says episodic rows are append-only *at the database level* (an
`EVENT` throws on `UPDATE`/`DELETE` where `category = 'episodic'`), and
`provenance.derived_from` exists specifically to link to episodic sources —
so any economics-mutating code path had to filter episodic records out
twice (once in Rust before building the statement, once as a redundant
predicate in the statement itself), or a recall/save touching an episodic
record would throw and fail the whole operation. This became the store test
suite's most important regression guard
(`citing_an_episodic_source_does_not_error_and_leaves_it_unmodified`,
`recall_never_touches_an_episodic_records_economics`).

Commit series, in order:
1. `tidy:` threaded `knn_distance` through `merge_chain` without changing
   `recall`'s behavior — verified by running the full pre-existing store
   suite immediately after, all green, before any scoring logic existed.
2. `test:` `totem-core::scoring` added with all five functions'
   bodies as `unimplemented!()` behind 16 real unit tests (decay
   monotonicity/boundedness, category-lifecycle-gated decay, category-weight
   ordering, relevance-from-distance monotonicity, combined-score algebra) —
   confirmed all 16 panicking for the right reason.
   `totem-store/tests/value_scoring.rs` added — 7 integration tests against
   the store as it stood (pre-feat); 3 genuinely failed (citation boost,

3. `feat:` real bodies for `totem-core::scoring`'s five functions (16/16

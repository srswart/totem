# Journey report — ADV-CLI-002

Workstation session, claim-first. `totem enroll` now authenticates, and the
repo enrolls against the deployed gateway: 1 system, 8 components, 44
advances.

## Two defects, one visible only from outside

The advance was written for the known gap — `enroll.rs` sent no
`Authorization` header. It found a second one that no test could have:
`totem-cli`'s `reqwest` had **no TLS backend**, so every `https://` URL was
refused with *"invalid URL, scheme is not http"* before a connection was
attempted. The CLI could not have reached any real deployment, credentials or
not.

The enroll tests spawn a **local HTTP listener** — exactly the shape that
hides a missing TLS feature. This is the third instance of one pattern in two
days: the MCP schema bug (in-process tests never read the published schema),
the unauthenticated clients (built against a gateway that never refused), and
now this. **The contract that matters is the one an external caller
exercises**, and every one of these was found by pointing a real client at a
real deployment.

## Choices worth recording

- Resolution happens **before** any work, so a first-time user's failure
  arrives before a landscape parse rather than after output that looks like
  progress.
- A stored credential bound to another repo is refused **locally** rather
  than presented — the gateway would answer 403, which is a worse error than
  "you have no credential for this repo".
- The sync hook carries **no token**. It resolves at run time, because a
  token in `.git/hooks` survives in backups and the hook runs unattended,
  which is when a leak goes unnoticed.
- `ResolvedCredential` has a hand-written `Debug` that redacts: the derived
  one prints the token, and this value reaches error paths and CI logs.

## Left untested, named

The hook's unattended path. It resolves from the local credential store, and
no store credential exists on this machine — the bootstrap token lives in a
file. It becomes testable when ADV-GATEWAY-012's issuance endpoints land,
which is where they were deliberately deferred to.

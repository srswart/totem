# Journey report — ADV-GATEWAY-015 (not reproduced, and that is the result)

The advance was written to fix a connector `totem_save` that completed
server-side while the client waited forever. **It did not reproduce.** Three
tests driving a real rmcp client over real HTTP — a save, a recall, and three
consecutive saves on one session — all acknowledge, and `curl` against the
deployed gateway gets a complete response in under a second with the stream
closing.

The advance had anticipated this: it required diagnosing before fixing and
explicitly permitted closing honestly if the cause proved to be client-side.
No server-side change was invented to make the work look productive.

## What the investigation found instead

**`json_response = true` never did anything for a real client.** rmcp 3.1.0
consults it on the stateless paths only; once a client holds a session — every
client, immediately after `initialize`, because the service mounts a
`LocalSessionManager` — a POSTed request returns SSE unconditionally. The
comment beside the setting asserted plain-JSON replies. It was false from the
day it was written, and survived because nothing drove the transport.

**The gateway compiled two reqwest stacks.** rmcp pulls 0.13.4; my own OAuth
work added 0.12. The TLS feature rename between the versions (`rustls-tls` →
`rustls`) hid it — the same detail that had already bitten ADV-CLI-002 from
the opposite direction, in the same day.

## The durable outcome

This crate had **no transport-level tests at all**. Everything went through
the handler in-process with typed arguments. That is the identical blind spot
that produced the published-schema bug and the CLI's missing TLS, and it now
has three timeout-bounded tests standing in it. The bug that prompted the
advance may still be out there; the class of bug that hid it is now harder to
repeat.

## Recorded as unresolved

Why claude.ai waited is unexplained. The plausible mechanism — SSE-framed
responses carrying a `retry` directive, inviting reconnect semantics — is
written down as a hypothesis, not a diagnosis, along with the three
observations that would settle it if it recurs.
